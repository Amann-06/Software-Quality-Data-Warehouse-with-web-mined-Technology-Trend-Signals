SQL
===

sql/bigquery/github_archive.sql should contain the extraction query used to obtain the 50K dataset.

Use:

SELECT
  id,
  created_at,
  type AS event_type,
  actor.login AS developer,
  repo.name AS repository,
  TO_JSON_STRING(payload) AS payload_json
FROM
  `githubarchive.day.20260901`
WHERE
  type IN (
    'PushEvent',
    'PullRequestEvent',
    'PullRequestReviewEvent',
    'PullRequestReviewCommentEvent',
    'IssuesEvent',
    'IssueCommentEvent',
    'ForkEvent',
    'ReleaseEvent'
  )
LIMIT 50000;

Do not execute this query automatically unless BigQuery credentials/configuration are available.

sql/warehouse/star_schema.sql:
Create the analytical schema.

sql/warehouse/olap_queries.sql:
Include representative roll-up, drill-down, slice, dice and pivot SQL.
